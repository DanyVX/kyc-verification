# Data policy

Only synthetic identities produced by `kyc.synth.generator` belong in this project. The generator creates fictional names and numbers and renders a conspicuous non-official card. It does not emulate NADRA security features or branding. No dataset, real ID, face image, or biometric embedding is committed.

The demo's generated images are test artifacts, not evidence that the system works on real documents. If volunteers are ever used outside this repository, obtain written consent and keep it privately.
